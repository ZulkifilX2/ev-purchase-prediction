# Predicting Electric Vehicle Purchases

End-to-end machine learning project for the Kaggle Playground
Series Season 6 Episode 9 competition.

## Objective

Predict the probability that a consumer will purchase an
electric vehicle.

## Evaluation

ROC-AUC

## Status

Competition in progress.

## Project Structure

- `notebooks/` — exploratory analysis and model experiments
- `src/` — reusable machine learning code
- `docs/` — experiment tracking and documentation
- `outputs/figures/` — generated analysis figures
- `data/` — local competition data, excluded from Git
